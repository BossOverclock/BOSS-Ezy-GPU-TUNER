## 🎯 Why Stability Matters
Chasing maximum theoretical clock speeds often leads to micro-stutters, thermal throttling, or driver crashes mid-game. Overclock-BOSS focuses on helping you find and lock in your hardware's true, sustainable ceiling so your frame times stay flat and predictable under heavy, sustained workloads.

## ✨ Features (v0.01)
* **🚨 All-Time First Hotspot Alarm System:** Real-time thermal warning system monitoring both **CPU and GPU hotspots**, alerting you immediately when temperatures creep into a high-risk zone.
* **📈 Stability-Focused Tuning:** Dial in clean, sustainable clock and powerlimits built to hold steady under load.
* **⚡ Lightweight & Direct:** Zero bloatware—just direct hardware communication and fast execution.

## ⚙️ How Control Works
Overclock-BOSS bridges industry-standard telemetry and low-level APIs into a single, reliable pipeline:
* **NVML (NVIDIA Management Library):** Handles direct low-level GPU state queries, power limits, and clock control.
* **Engine CLI:** Executes profile applications and automated tuning routines cleanly.
* **HWiNFO Integration:** Reads granular sensor telemetry—specifically tapping into CPU and GPU hotspot sensors—to drive the real-time thermal alarm system.

## 🛠️ Build & Publish

### Prerequisites
* Windows 10 / 11 (64-bit)
* NVIDIA GPU with updated drivers (for NVML support)
* [HWiNFO](https://hwinfo.com) installed (with Shared Memory Support enabled for sensor polling)
